# 第77章 调查结果出炉

8月26日，晚上7点。

方远坐在出租屋的沙发上，手里拿着手机，眼睛盯着屏幕。

手机很安静，没有任何消息。

他已经在等了3个小时——从下午4点开始，他就在等调查人员的电话。

调查人员说，结果这两天就出来。

今天是8月26日，距离他们说的"8月27日或28日"还有1-2天。但方远心里总觉得，结果可能提前出来。

"系统，"方远在心里唤道，"你说，结果会顺利吗？"

"不知道，"系统说，"但根据之前的检测，应该没问题。你的番茄，没有任何违规成分。"

方远点了点头。

他知道系统说得对。但心里还是不安。

等待的煎熬，比直接的失败更难受。

就在这时，手机突然响了。

方远的心跳加速，他看了一眼来电显示——陌生号码。

他接起电话。

"喂，你好。"

"方先生吗？"电话那头是一个男人的声音，"我们是市场监督局的调查小组。"

方远的心跳到了嗓子眼。

"我是。"他说。

"方先生，恭喜你。"调查人员说，"检测报告已经出来了，所有指标都合格。"

方远愣了一下。

"合格？"

"对，合格。"调查人员说，"营养成分、安全性、无激素、无转基因，所有指标都符合国家标准。你的番茄，是真正的绿色食品。"

方远长出了一口气。

悬在心里的石头，终于落地了。

"谢谢，谢谢你们。"他说。

"不客气。"调查人员说，"另外，你需要来一趟局里，领取正式的检测报告。"

"好的，我马上过去。"

方远挂了电话，站起身。

他看向窗外，天色已经暗了下来。路灯亮起，街道上车流不息。

"系统，我合格了。"

"我知道。"系统笑了，"我早就说过，你的番茄没问题。"

方远笑了笑。

他拿起外套，推开门，走下楼梯。

...

市场监督局在城市的东边，距离方远住的地方有十多公里。

方远坐了一个小时的公交车，终于到了。

他走进大厅，找到调查小组的办公室。

"方先生？"一个工作人员抬头看了他一眼。

"对，我是方远。"他说。

"好的，请稍等。"工作人员翻了翻文件，拿出一份报告，"这是你的检测报告。"

方远接过报告，翻开了第一页。

**检测报告**

**样品名称**：发光番茄
**检测时间**：2026年8月15日-8月25日
**检测结果**：合格

**检测项目**：

1. 营养成分：维生素C含量、番茄红素含量、叶酸含量，均超出普通番茄50%以上。
2. 安全性：无农药残留、无重金属、无有害物质。
3. 激素检测：未检出任何激素类物质。
4. 转基因检测：未检出转基因成分。

**结论**：该样品为真正的绿色食品，符合国家食品安全标准。

方远一条一条地看着，心里涌起一股释然。

终于，自证清白了。

他继续翻页，看到了最后一页——调查小组的签名和公章。

红色印章清晰可见，证明这份报告的真实性和权威性。

"方先生，"工作人员说，"你可以把这份报告发布到网上，或者提供给媒体。这样，之前的质疑就会不攻自破。"

"好的，谢谢。"方远说。

他拿起报告，转身准备离开。

就在这时，门口突然传来一阵急促的脚步声。

"不可能！我不相信！"

一个熟悉的声音传来。

方远转过身，看到了李老板。

李老板脸色难看，眼神里充满了不甘和愤怒。

"你们是不是搞错了？"李老板冲到工作人员面前，"他的番茄怎么可能合格？你们肯定收了他的钱！"

工作人员皱了皱眉头。

"李先生，请注意你的言辞。"工作人员说，"我们严格按照国家流程进行检测，数据真实可靠。如果你对结果有疑问，可以申请第三方检测。"

"第三方检测？"李老板冷笑，"你们都是一伙的！"

方远走上前。

"李老板，"他说，"你输了。"

李老板转过头，眼神冰冷地看着方远。

"我输？"他咬牙切齿，"我不相信！你的番茄肯定有问题！你们肯定在造假！"

"李老板，"方远平静地说，"你可以继续质疑。但事实就是事实。我的番茄，通过了所有检测。"

他举起手中的报告。

"这是官方的检测报告，有签名，有公章。你可以自己看。"

李老板一把抢过报告，快速翻阅。

他的脸色越来越难看。

"不可能..."他喃喃自语，"不可能..."

他把报告扔回给方远，转身就走。

但走了两步，他又停了下来。

他转过头，眼神阴沉地看着方远。

"方远，"他说，"我不会善罢甘休的。你等着。"

方远心里一紧。

"你什么意思？"他问。

"我的意思很明确。"李老板冷笑，"你以为有了这份报告，就赢了？不，你才刚刚开始。"

他停顿了一下。

"我会让你付出代价的。"

说完，他转身大步离开，消失在走廊尽头。

方远站在原地，心里涌起一股不安。

李老板不会放弃。

新的危机，在后头。

...

方远回到出租屋时，已经是晚上10点了。

他坐在沙发上，手里拿着检测报告，心里却高兴不起来。

危机解除了，但新的危机在酝酿。

"系统，"方远问，"李老板会做什么？"

"不知道。"系统说，"但根据他的性格，他不会轻易放弃。"

方远点了点头。

李老板是传统农业协会的成员，他有一定的影响力。如果他想报复，有很多手段。

造谣、举报、打压...

"宿主，"系统说，"你需要做好准备。"

"什么准备？"

"两手准备。"系统说，"第一，继续种植发光番茄，正常销售。第二，准备启动变异体B计划，作为后手。"

方远沉默了。

变异体B计划——他之前确定的方案。

如果李老板真的报复，他需要有一条后路。

但问题是，现在种植变异体，可能会引起李老板的注意。

"系统，如果我种植变异体，李老板会发现吗？"

"可能。"系统说，"变异体的生长周期是38天，如果现在种植，10月中旬就能收获。但李老板如果持续监视你，他可能会发现。"

方远想了想。

"那...我暂时不种植变异体。先观察李老板的动向。"

"可以。"系统说，"但你需要记住，如果李老板真的采取行动，你要及时启动变异体B计划。"

方远点了点头。

他站起身，走到窗边。

窗外，城市的夜景美丽而宁静。

但他知道，在这份宁静之下，暗流涌动。

李老板不会放弃。

新的风暴，正在酝酿。

方远深吸了一口气。

无论如何，他已经准备好了。
