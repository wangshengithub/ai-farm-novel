# 第179章 复查日

五月十一日。

早上八点半，方远和林小雅离开农场，前往市第一人民医院。

昨天，系统说："明天上午九点复查。医生会根据过去十天的数据评价您的进步。"

系统说："根据数据分析，您的认知内化已经成功。控制欲反弹周期——结束了。"

方远说："明天见。"

今天，就是复查日。

林小雅开车，方远坐在副驾驶。

"紧张吗？"林小雅问。

"不紧张。"方远说，"系统已经确认了认知内化成功。我知道我做到了。"

林小雅看着他，笑了。"但我记得——十天前你出院的时候，你也很自信。"

"那是装的。"方远说，"这次是真的。"

"真的？"

"真的。"方远说，"十天前，我几乎无法控制插手冲动。每次电话响，我的手都会伸出去。即使系统提醒，我也需要挣扎8秒、7秒、6秒才能松开手。"

他顿了顿。

"但昨天——"方远说，"系统完全停止了所有提示。没有心率数据，没有插手提醒，什么都没有。"

"四次考验，我握住听筒的时间从7秒缩短到3秒。"方远说，"而且我越来越从容。"

林小雅看着他，眼神中带着欣慰。

"我相信你。"

车子驶入医院停车场。

九点整，方远和林小雅来到心内科诊室。

李医生的诊室。

方远推开门，林小雅跟在身后。

李医生抬头，看到方远，笑了。"方先生，请坐。林小姐也请坐。"

方远和林小雅坐下。

"今天是复查日。"李医生说，"让我看看您过去十天的健康数据。"

他打开电脑，调出方远的健康记录。

方远看着李医生的屏幕。

屏幕上显示着过去十天的完整数据：

**健康数据轨迹（5月1日-5月10日）**：
- 心率峰值：143 → 141 → 138 → 135 → 130 → 132 → 137 → 137 → 139 → 139
- 握住听筒时长：8秒 → 7秒 → 6秒 → 5秒/7秒 → 5秒/4秒 → 5秒/6秒/7秒/8秒 → 7秒/5秒/5秒/3秒
- 健康评分：55 → 56 → 57 → 58 → 58 → 58 → 57 → 58 → 58 → 59

李医生看着这些数据，眉头皱了起来。

方远的心跳开始加速。

医生为什么皱眉？是数据不好吗？

李医生继续滚动屏幕，查看更详细的数据。

**系统记录的考验详情**：
- 5月1日（第169章）：心率143次/分，握住听筒8秒，几乎失控
- 5月2日（第170章）：心率141次/分，握住听筒7秒，挣扎严重
- 5月3日（第171章）：心率138次/分，握住听筒6秒，略有进步
- 5月4日-6日（第172-174章）：心率130-135次/分，握住听筒5-7秒，学会主动健康参与
- 5月7日（第175章）：心率132次/分，握住听筒5秒、4秒，理解进步非线性
- 5月8日（第176章）：心率137次/分，握住听筒5秒、6秒，验证认知内化
- 5月9日（第177章）：心率137次/分，握住听筒3秒、6秒、7秒、8秒，验证持续性
- 5月10日（第178章）：心率139次/分，握住听筒7秒、5秒、5秒、3秒，系统完全停止提示

李医生的眉头越皱越紧。

方远的手心开始出汗。

李医生终于抬起头，看着方远。

"方先生——"李医生停顿了一下，"这些数据，来自哪里？您的智能设备吗？"

"是系统记录的。"方远说，"我出院后，系统开始健康管理功能，每天记录我的健康数据。"

李医生看着方远，眼神中带着惊讶。

"一个智能健康管理系统？"李医生问。

"是的。"方远说。

李医生看着屏幕，手指缓慢滑动。"这非常详细——心率峰值、握住听筒时长、健康评分...甚至标注了每次考验的类型和持续时间。"

他抬起头，眼神中带着专业的好奇。"能告诉我——'系统'是如何判断'健康应对'的？"

"系统会实时监控我的心率、血压、呼吸等生理指标。"方远说，"当电话响、有人敲门、出现突发状况时，如果我的心率超过阈值、我的手伸向电话、我的肌肉紧绷——系统会判断这是'插手冲动'。"

"然后——"方远说，"系统会提示我的心率，提醒我不要插手。"

李医生听着，眼神从疑惑变为理解。

"所以——"李医生说，"您出院后的这十天，这个系统一直在帮助您控制插手冲动？"

"前九天是的。"方远说，"但昨天——5月10日，系统完全停止了所有提示。"

"完全停止？"李医生问。

"是的。"方远说，"没有心率数据，没有插手提醒，什么都没有。系统说这是'最终验证'——测试我能否在没有系统任何帮助的情况下，完全自主应对。"

李医生看着屏幕上的数据，眼神中带着惊讶。

"5月10日——"李医生说，"您在四重压力叠加的情况下，握住听筒的时长从7秒缩短到3秒。"

"是的。"方远说。

李医生停顿了一下。

"方先生，我必须说——"李医生说，"这种方法非常科学。"

"什么方法？"方远问。

"建立一个外部监控体系，帮助自己重塑内部行为模式。"李医生说，"这就是认知行为疗法的核心原理——通过外部反馈帮助患者建立新的行为模式，最终实现内部化。"

他顿了顿。

"方先生——"李医生说，"我必须祝贺您。从数据来看，您的进步非常显著。"

他指着屏幕上的数据。

"您知道吗？"李医生说，"大多数患者，在面对工作压力时，心率峰值会持续上升。但您的心率峰值，从143下降到139，虽然有波动，但总体趋势是下降的。"

"更关键的是——"李医生说，"您握住听筒的时长，从8秒缩短到3秒。这意味着您的控制能力在本质上的提升。"

方远松了一口气。

"系统说——"方远说，"这是认知内化的标志。"

"认知内化？"

"就是——"方远说，"我知道什么是不健康的，但我不再需要外部提醒来阻止自己。我能够自己做出健康的选择。"

李医生点了点头。

"这正是我们希望看到的。"李医生说，"您已经从'被动控制'转向了'主动管理'。"

他顿了顿。

"方先生，从数据来看——"李医生说，"您的控制欲反弹问题，已经得到了显著改善。"

方远看着李医生，眼神中带着释然。

"显著改善？"方远问。

"是的。"李医生说，"握住听筒时长的缩短、心率峰值的下降、健康评分的提升——这些都证明了您的本质改变。"

他顿了顿。

"当然——"李医生说，"这并不意味着您以后不会有压力。工作的压力依然会存在，但您现在有能力应对这些压力，而不失控。"

方远看着李医生，笑了。

"谢谢您，李医生。"

"不客气。"李医生说，"这是您自己的努力换来的。"

他合上电脑，看着方远和林小雅。

"方先生，我建议您——"李医生说，"后续保持定期复查，每两周一次，持续三个月。这样可以确保您的康复进展稳定。"

"好的。"方远说。

"另外——"李医生说，"复工后，建议您保持健康的工作方式。每天工作不超过8小时，每周至少休息一天。避免连续高强度工作。"

"好的。"方远说。

"还有——"李医生说，"如果感到压力增大，可以随时联系我。"

"谢谢您。"

李医生站起来，伸出手。

"方先生，再次祝贺您。"李医生说，"您的进步非常显著，继续保持。"

方远站起来，握住李医生的手。

"谢谢您。"

三人离开诊室。

方远和林小雅走出医院，阳光照在身上。

五月十一日，复查日。

方远看着林小雅，笑了。

"医生说——显著改善。"方远说。

林小雅看着他，笑了。

"我早就知道了。"林小雅说，"因为——前十天，我每天都在看着你进步。"

方远看着她，笑了。

"谢谢你。"

"不客气。"林小雅笑了，"我是你女朋友，这是我的工作。"

两人走向停车场。

【方远，恭喜。】系统的声音突然响起。

方远愣了一下。"系统？你不是说——结束了？"

【控制欲反弹周期结束了。】系统回答，【但新的健康管理周期，今天开始。】

"新的周期？"

【复工后，您将面临新的压力。】系统说，【接下来的三个月，系统将以"隐性监控"模式运行——只在您需要时提供支持，而非实时提示。】

【这是从"学习"到"应用"的过渡。】

方远看着天空，笑了。

"我准备好了。"

【很好。】系统说，【新周期——开始。】

五月十一日，复查日。

旧的周期结束了。

新的周期——开始了。

方远笑了。

前十天，他做到了。

未来——他也能做到。
