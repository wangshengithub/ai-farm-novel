# 第206章 从0到1的突破

6月23日中午，楼顶农场工作区。

方远盯着屏幕上的两个选项。

选择A：重新打样。花费300元，等待2-3天，但风险更小。

选择B：直接批量印刷。节省成本和时间，但风险存在。

他打开了Excel，开始建立决策模型。

"如果选择B，直接印刷，成本是1550元。"他自言自语，"但如果75-80分的设计，实物化后只有65-70分，我就要承担两个风险。"

他顿了顿。

"第一，客户收到包装后，满意度可能不够高。第二，如果问题严重，我可能要重新印刷，成本会翻倍。"

他在Excel里列出概率分析：

"假设65-70分的实物，有30%概率客户不满意，需要重新印刷。"

他在Excel里输入公式。

"那么期望成本是1550 + 1550×30% = 2015元。而选择A的期望成本是1850元。"

他看着结果。

"从数学角度看，选择A更优。"

他合上电脑，准备下单重新打样。

"方远。"

系统的声音响起。

"你又在做什么?"

"决策分析。"方远说，"我用Excel计算了期望成本，选择A的期望成本是1850元，选择B的期望成本是2015元。所以选择A更优。"

"这是Excel思维。"系统说。

"可是这是数学啊!"方远说，"期望成本计算是理性的决策方法。"

"但你忽略了一个变量。"系统说，"时间成本。"

"时间成本?"

"选择A需要等待2-3天，选择B可以立即印刷。"系统说，"在这2-3天里，你失去了什么?"

方远想了想："失去了……提前进入市场的时间?"

"对。"系统说，"创业不是做数学题，是在不确定的环境中快速迭代。你花时间计算期望成本，不如先让产品进入市场，获得真实的客户反馈。"

"但是……"方远说，"如果产品有问题，客户不满意怎么办?"

"那就改进。"系统说，"客户不满意是正常的。你第一次打样，发现了三个问题，这不是失败，是学习。如果客户反馈新的问题，你再改进，这是创业的规律。"

方远沉默。

他想起了第203章。当时系统说"行动比犹豫更重要"，他接受了，决定打样。但现在看到实物只有60分，Excel思维又复发——他又想找标准答案了。

"系统……"他说，"我很害怕。"

"害怕什么?"

"害怕做错选择。"方远说，"如果选择B，直接印刷，结果客户很不满意，我就浪费了1550元。如果选择A，重新打样，花300元，等待2-3天，结果发现75-80分的设计，实物化后还是只有65-70分，那我又浪费了300元和2-3天。"

"方远，创业没有标准答案。"系统说，"你不可能在行动前就知道结果。你只能做决定，然后承担结果，然后继续前进。"

"但是……"方远说，"我想做最优决策。"

"没有最优决策，只有决策。"系统说，"你现在花费在计算期望成本上的时间，已经超过2小时了。这2小时，你本可以用来做更有价值的事情。"

方远看着电脑屏幕上的Excel表格。

手指悬在回车键上，半天没按下去。

系统说得对。他又在找标准答案了。

"关掉Excel。"系统说。

方远的胸口起伏了一下，关掉了Excel。

"现在，凭直觉做决定。"系统说，"你想选A还是B?"

方远想了想："我选A。"

"为什么?"

"因为……"方远说，"我至少想看到75-80分的设计，实物化后是什么样子。我想先验证一下，再批量印刷。"

"好。"系统说，"那就下单。"

方远打开印刷厂的网站，选择了重新打样，支付了300元。

"预计2-3天完成。"网站显示。

方远关上电脑。

"Excel思维复发次数：+1。"系统说。

方远苦笑。

他知道，Excel思维已经刻在他的基因里了。虽然工作狂基因降到了3%，但Excel思维——试图用数据分析找到标准答案的思维模式——仍然会在关键时刻复发。

"没关系，慢慢来。"系统说，"至少你这次在2小时内做出了决定，上一次你犹豫了3天。"

方远点头。

他转身去温室，继续照料蔬菜。

傍晚过去了，夜幕降临。

---

6月24日上午九点，楼顶农场工作区。

"叮铃铃——"

"快递，楼下有包裹。"

方远冲下楼，两分钟后跑回楼顶，手里拿着新的纸箱。

拆开，里面是新的包装盒。

圆形透明窗口的位置下移了1.5厘米——这是他自己想出来的。

内部尺寸加宽了0.5厘米——也是他想出来的。

材质改为了300g牛皮纸——同样如此。

方远拿起包装盒。

他转身去温室，拿了六个鸡蛋回来。

把第一个鸡蛋放入圆形窗口——

这次，鸡蛋露出了恰到好处的部分，圆形的轮廓在透明窗口中清晰可见。

他又拿了一个鸡蛋，从侧面放入包装盒。鸡蛋不晃了，刚好卡在内部空间里。

六个鸡蛋全部放进去后，轻轻摇晃——没有碰撞的声音。

方远拿起包装盒，晃了晃。300g牛皮纸的厚度，承重明显更好。

"系统。"他说。

"实物72分。"系统说，"设计稿75-80分，实物化后下降3-8分，但已经达到可接受水平。"

方远松了一口气。

1550元 + 300元 = 1850元。从65分的设计，到72分的实物，这个投入是值得的。

"可以批量印刷了吗?"他问。

"可以。"系统说，"但你要决定印多少。"

印刷厂的网站上显示：起印量500个，价格约1500-2000元，具体取决于材质和工艺。

方远想了想："印500个吧。"

他选择了批量印刷，支付了1800元。

屏幕上弹出提示：

```
【品牌建设】学习进度:64% → 68%(+4%)
```

"预计2-3天完成。"网站显示。

方远关上电脑。

接下来是2-3天的等待时间。在这期间，他需要准备上架信息——产品照片、产品描述、价格定位。

他打开手机，翻出之前拍的照片。

第一批鸡蛋的照片，在温室里拍的，背景是绿油油的蔬菜。

包装盒的照片，打样的那个，圆形窗口的位置偏了，鸡蛋只露出顶端。

"不行，得重新拍。"方远说。

他拿起新的包装盒，去温室拿了六个鸡蛋，精心摆放。

鸡蛋在圆形窗口中露出恰到好处的部分，背景是温室里的蔬菜，阳光透过玻璃照进来。

咔嚓。

照片拍好了。

接下来是产品描述。方远想了想，写下了：

"楼顶农场散养鸡蛋，每只鸡每天至少自由活动8小时，吃有机蔬菜叶子和玉米。包装自己设计的，虽然不完美，但诚意满满。六枚装，18元。"

他看了一眼价格。

18元六枚装，平均每枚3元。市场上普通鸡蛋1-1.5元一枚，有机鸡蛋2-2.5元一枚。他的定价略高，但考虑到包装成本和"楼顶农场"的故事性，应该可以接受。

他把产品信息和照片发到了朋友圈。

---

6月24日下午三点，楼顶农场工作区。

方远正在温室里浇水，手机响了。

他拿起手机，看到一个陌生的号码发来的消息：

"你好，我在朋友圈看到你的鸡蛋，想买两盒试试。"

方远愣住了。

第一个客户!

他赶紧回复："好的，你要两盒是吗?一共36元，你可以微信支付。"

"好的，我转给你。"

一分钟后，微信收到36元转账。

"你的地址是哪里?我给你发货。"方远回复。

"不用发货，我自己来拿。我就住附近，大概半小时后到。"

方远放下手机，心脏狂跳。

半小时后，楼下传来声音："方远在吗?"

方远冲下楼，看到一位三十多岁的女性，穿着职业装，手里提着购物袋。

"你好，我是方远。"他说。

"你好，我在朋友圈看到你的鸡蛋，想试试。"女性说，"包装挺好看的，自己设计的?"

"嗯，自己学的。"方远有些不好意思。

"厉害。"女性说，"那给我两盒吧。"

方远转身跑上楼，去温室拿了十二个鸡蛋，装进两个包装盒。

他把包装盒递给女性。

女性接过包装盒，看了看："嗯，鸡蛋很新鲜，包装也挺有质感的。多少钱?"

"36元，你已经转过了。"方远说。

"好，谢谢。"女性说，"如果好吃，我再买。"

她转身离开了。

方远站在原地，看着她的背影消失在楼梯转角。

第一个客户，成交了!

他打开手机，想把这个好消息告诉系统，但手机又响了。

这次是一个电话。

"你好，方远吗?"

"是的。"

"我在朋友圈看到你的鸡蛋，想买五盒。可以吗?"

"可以!"方远说，"五盒是90元，你要自己来拿吗?"

"对，我一会儿过去。"

方远挂了电话，还没来得及兴奋，手机又响了。

另一个电话："你好，我买三盒。"

"好的。"

"你好，我买四盒。"

"好的。"

方远忙不过来了。

他冲上楼，去温室拿鸡蛋，装盒，然后下楼交给客户。

一个接一个，客户来了又走。

到了下午五点，方远数了数，一共卖出了20盒——120个鸡蛋。

他打开手机银行，看了一眼余额。

360元入账。

这是他第一次通过销售产品获得收入。

不是打工的工资，是真正的创业收入。

"系统。"他说。

"嗯。"系统的声音响起。

"我卖出去了20盒。"方远说，"360元。"

"恭喜。"系统说。

"而且……"方远说，"还有几个客户说，如果好吃，还会再来买。还有个客户说，要把我的鸡蛋推荐给朋友。"

"这就是品牌的力量。"系统说，"产品好，包装好，故事好，客户就会信任你，然后推荐给别人。这是从0到1的突破。"

方远看着温室里的鸡。

鸡们在悠闲地散步，啄食着蔬菜叶子和玉米。

它们不知道，它们的蛋，正在成为一个小小的品牌。

屏幕上弹出提示：

```
【品牌建设】学习进度:68% → 75%(+7%)
工作狂基因:3%
```

方远笑了。

他从椅子上站起来，走到温室门口，看着远处的城市。

第一次打样60分，第二次打样72分，今天卖出20盒。

路走对了。

---

6月24日晚上八点，楼顶农场工作区。

方远坐在电脑前，整理今天的订单。

20盒，360元。

成本方面：两次打样共1850元（第一次1550元+第二次300元），批量印刷1800元，鸡蛋成本约120元（每个鸡蛋1元成本），人工不算。

总成本3770元，收入360元，还亏3410元。

但方远不觉得沮丧。

因为今天有客户说"包装挺有质感的"，有客户说"如果好吃还会再来买"，还有客户说要推荐给朋友。

这是从0到1的突破。

最重要的是，客户来了——不是靠推销，不是靠广告，是靠朋友圈的口碑。

方远打开微信，看到又有新消息：

"你好，方远，我朋友推荐你的鸡蛋，想买三盒。什么时候有货?"

方远愣住了。

这是推荐客户!

他赶紧回复："有的，你要自己来拿吗?"

"对，我明天过来。"

方远放下手机，心脏狂跳。

推荐客户意味着什么?

产品被认可了。品牌开始建立了。从0到1，突破了。

"系统。"他说。

"嗯。"

"我收到了推荐客户。"方远说，"客户的客户。"

"恭喜。"系统说，"这是品牌初步成功的标志。"

方远沉默了很久。

"系统，我今天卖出了20盒，收入360元。"他说，"但成本是3770元，我还亏3410元。"

"你觉得亏吗?"系统问。

"不觉得。"方远说，"因为今天我看到了从0到1的突破。"

"很好。"系统说，"那么，你准备好迎接下一个挑战了吗?"

"下一个挑战?"

"订单增加。"系统说，"今天20盒，用掉了你过去3-4天积累的库存鸡蛋。按你的产蛋量，每天只能产30-40个鸡蛋，也就是5-6盒。如果明天复购率很高，订单超过了供应能力，你会面临新的问题。"

方远愣住了。

他还没想过这个问题。

今天卖出20盒，是因为库存里有鸡蛋。但如果明天、后天、大后天，订单继续增长呢?

他的鸡每天只能产30-40个蛋，这是物理限制。

如果订单超过了供应能力，他要么扩大养殖规模，要么拒绝订单。

扩大养殖规模意味着需要更多的空间、更多的饲料、更多的人手。

拒绝订单意味着失去客户机会，伤害品牌声誉。

这是一个新的困境。

方远打开Excel，想计算一下最优策略。

鼠标悬停在新建按钮上，他的手在微微颤抖。

脑海里响起了系统的声音：创业不是做数学题，是在不确定的环境中快速迭代。

他闭上眼睛，再睁开，手从鼠标上移开。

他关掉了Excel。

"系统，我该怎么做?"他问。

"不是计算，是决策。"系统说，"你还没遇到这个问题，但很快就会遇到。到时候，你要做决定。"

方远点头。

他知道，Excel思维又想复发了——他想提前计算好所有可能的解决方案，想找到标准答案。

但创业不是这样的。

创业是遇到问题，然后解决问题。

现在，他还没有遇到这个问题，不需要提前焦虑。

他只需要准备好迎接明天的订单。

方远关上电脑，起身去温室。

鸡们已经睡了，安静地趴在栖木上。

方远给它们加了一些饲料，然后关灯离开。

明天，又是新的一天。
