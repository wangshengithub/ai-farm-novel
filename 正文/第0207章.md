# 第207章：意识到需要人手

晚上九点，楼顶农场工作区。

方远刚放下打包盒，手机屏幕又亮了。

两条新消息接连弹出：

"方远，还有鸡蛋吗？我朋友听说后也想买两盒。"
"小方啊，明天能留五盒吗？我单位同事想团购。"

方远盯着屏幕，手指悬在回复键上，半天没点下去。

今天卖了20盒，360元收入。听起来不错？但他知道账本上的数字：两次打样1850元，批量印刷包装盒1800元，加上鸡蛋成本120元，总投入3770元，净亏3410元。

这些都不重要。

重要的是，之前推荐的那些客户，今天有两人下单了。

从0到1的突破。

【系统：品牌建设学习进度 75% → 80%】
【恭喜完成里程碑：首次客户成交、首次推荐转化】

方远刚想松口气，系统界面突然红色闪烁。

【⚠️ 预警：供应能力危机】

他手一抖，差点把手机掉在桌上。

点开系统界面，红色曲线刺眼地向上攀升：

当前产能：40只鸡，每天产30-40个鸡蛋（可做5-6盒包装）
今日销售：20盒（消耗120个鸡蛋）
库存剩余：约可供应2-3天

下面是两行加粗的红色字：
如果复购率保持80%，3天后将断货。
如果推荐转化持续增长，缺口会进一步扩大。

方远盯着这些数据，额头冒出了一层细汗，喉咙发干。

他本能地打开手机上的Excel应用，手指在屏幕上快速输入，指尖有些发抖。熟悉的表格界面让他感到安心，仿佛回到了自己掌控的领域。

屏幕上的数字跳动：

方案A：自己扩大养殖规模。

- 需要增加鸡舍面积15㎡（约2000元）
- 购买鸡苗20只（约1000元）
- 增加饲料投入（每月约300元）
- 预计需要3个月见效，但订单等不了3天。

方案B：招聘人手帮忙。

- 月薪约3000-4000元
- 管理成本：培训时间、信任风险、质量控制
- 2周就能见效，短期有成本但长期收益更高。

方案C：拒绝部分订单。

- 短期可以缓解供应压力
- 但损害品牌信誉，客户流失率可能上升30%
- 以后再想挽回就难了。

方远盯着这些数字，额头上的汗更多了。

"你又在做期望成本计算了？"

系统突然弹出对话框，字体带着明显的无奈。

方远头也不抬，手指继续在屏幕上飞快输入："我要理性分析啊。这么多方案，不计算清楚怎么选？"

"那你忽略了一个变量：时间。"

系统界面一闪，新的数据浮现，每一行都像一记重锤：

方案A（自己干）：3个月才能扩大规模，但订单等不了。客户等3天没货，就去别家了。

方案B（招人）：2周就能见效，短期会有管理成本，但长期收益更高。

方案C（拒单）：品牌信誉受损，以后再想挽回就难了。

方远的手指停在屏幕上。

他看着这些数据，沉默了。

系统继续说道："方远，创业不是一个人战斗，是构建系统。你现在的问题不是'能不能做'，是'敢不敢放手'。"

放手？

方远靠在椅背上，喉结滚动了一下。

窗外天色渐暗，城市的灯火一盏盏亮起。他的思绪回到第1卷刚开始的时候。那时他一个人种菜，一个人浇水，一个人打包，一个人配送。每天凌晨四点起床，晚上十一点才休息，累得像条狗。但他那时很安心，因为所有事情都在自己掌控中。

只有自己做的，才放心。教别人太麻烦，还要反复检查。招人的成本太高了，工资、社保、管理...

这些念头在他脑海里盘旋。

"你记得林小雅怎么帮你直播的吗？"系统突然问道。

方远愣了一下。

是啊，林小雅第一次帮他直播的时候，他也很紧张。担心她说错话，担心她不会介绍产品，担心观众不喜欢。他在镜头外站着，手心全是汗。

但结果呢？

林小雅的直播让品牌曝光加速了10倍。她比他更擅长与人交流，更懂得调动气氛。

"团队不是成本，是杠杆。"系统继续引导，"1个人×10小时 < 10个人×1小时。这不是减法，是乘法。"

方远盯着系统界面，久久没有说话。

终于，他深吸一口气，拿起手机，拨通了林小雅的电话。

"喂？方远？"林小雅的声音从听筒里传来，带着一丝惊喜，"今天辛苦了！销量这么好，恭喜啊！"

"销量好是好，但供应跟不上了..."方远苦笑了一下，"今天卖了20盒，把我3-4天的库存都用掉了。如果复购率上来，我肯定供不上。"

"那就招人啊！"

林小雅的反应比他预想的快得多，语气轻松得像在说"今天天气不错"。

"可是...我不会招人，也不知道招什么样的人。"方远承认道，"而且管理起来很麻烦，我怕..."

电话那头沉默了几秒。

"其实..."

林小雅的声音里多了一丝犹豫，然后又坚定起来，"我以前在公会管理过主播招聘，有经验。我知道怎么筛选人，怎么培训，怎么管理。"

方远愣住了："真的？我从来没听你说过..."

"以前那是工作，现在..."林小雅笑道，"明天来农场，我们细聊。我帮你列一个招聘计划，保证找到合适的人。"

"那...太好了..."

方远挂断电话，长长地松了一口气。

他感觉心里的一块石头终于落地了，肩膀也随之放松下来。

【系统：好感度+5，林小雅对你的信任度提升】

系统界面再次弹出：

"第一个员工很关键，会影响整个团队文化。选对了，事半功倍。选错了，后患无穷。"

方远看着这行字，心里既有期待，又有一丝不安。

他转头看向窗外，夜空中星星点点，城市的灯火在远处闪烁。风吹过楼顶，带来远处公路上隐约的车流声。

明天，林小雅会来农场，带来第一份招聘计划。

而他的农场，将迎来第一个员工。
