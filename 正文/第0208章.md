# 第208章：招聘计划

第二天一早，方远刚喂完鸡，就听到楼顶传来脚步声。

林小雅背着电脑包，手里拿着一叠打印好的资料，脸上带着疲惫但兴奋的笑容。

"我昨晚熬夜做的招聘计划，你看行不行。"她把资料放在工作台上。

方远拿起资料，第一页是一张清晰的表格：

| 模块   | 内容         |
| ---- | ---------- |
| 岗位分析 | 我们需要什么样的人？ |
| 渠道选择 | 去哪里招人？     |
| 筛选标准 | 怎么判断合适？    |
| 面试问题 | 问什么能看出态度？  |
| 培训计划 | 前两周怎么教？    |
| 试用期  | 双向选择       |

"你太专业了，"方远惊叹，"我完全没想到这么多。"

林小雅笑了笑："我以前在公会管理过主播招聘。招主播和招农场助手，其实逻辑一样——不是找最优秀的人，是找最合适的人。"

方远翻开第二页，是详细的岗位分析。

"核心问题：我们需要什么样的人？"林小雅指着第一行，"这个问题你想过吗？"

方远沉默了几秒："我...我也不知道。可能需要会养鸡的？能吃苦的？"

林小雅摇摇头："这些都是表象。你真正需要的，是三个特质：责任心、学习能力、热爱农业。其中，责任心是第一位的。"

她看向方远，眼神认真："方远，你可以教会一个人种地，但教不会他责任心。技能可以学，态度很难改。"

方远若有所思地点点头。

【系统：团队组建学习进度 0% → 5%】

系统界面弹出：

『正在分析当地劳动力市场数据...』
『分析完成』

"当地类似岗位的薪资范围在2800-4500元之间，"系统显示数据，"建议你定在3000-4000元，处于市场中位，既不会太高增加成本，也不会太低招不到人。"

林小雅赞同："3000-4000元合理。但除了薪资，更重要的是岗位定位。"

她翻开资料第三页："我们不是在招'工人'，是在招'农场助手'。这两个词的区别是什么？"

方远想了想："工人...就是干活的？助手...是帮忙的？"

"对，但不全对。"林小雅解释，"工人是被动的，只负责执行，只关注工资。助手是主动的，可以参与决策，更关注成长。"

她指着资料上的关键词："所以我们的招聘定位不是'找工人'，而是'找伙伴'。"

方远眼神一亮："伙伴？"

"对，伙伴。"林小雅点头，"这个人会和你一起工作，会接触到你的核心技术和经营理念。如果只是把他当工人，他也会把自己当工人。但如果把他当伙伴，他才会真正投入。"

【系统：提示——人才筛选逻辑已解锁】

"那么，去哪里招人？"方远问道。

林小雅翻开第四页："渠道选择很重要。我建议三个方向："

"第一，本地招聘平台。58同城、BOSS直聘这些，流量大，简历多。但缺点是鱼龙混杂，需要花时间筛选。"

"第二，熟人推荐。这个渠道最靠谱，因为有人背书。但缺点是数量有限，而且万一不合适，面子上过不去。"

"第三，农业相关的社群或论坛。比如养鸡交流群、城市农业论坛这些。优点是目标精准，缺点是活跃度可能不高。"

方远皱眉："熟人推荐...万一不合适怎么办？"

"所以要有试用期。"林小雅说，"前两周双向选择。不合适，好聚好散。而且熟人推荐的人，通常不会太离谱。"

【系统：招聘成本分析】
『平台费用：约50-200元』
『时间成本：筛选简历约2-5小时』
『试错成本：试用期2周，成本约1500-2000元』
『建议：熟人推荐试错成本最低，优先推荐』

"系统说得对，"方远看着数据，"熟人推荐确实最靠谱。"

林小雅笑了："那就这样，主渠道用本地招聘平台，辅助渠道让熟人帮你转发朋友圈。双管齐下。"

方远点点头，打开手机上的招聘APP，开始填写信息。

标题：招农场助手

任职要求：

1. 吃苦耐劳
2. 有养殖经验
3. 听从指挥

工作内容：喂鸡、收鸡蛋、打扫鸡舍

薪资：面议

"填好了，"方远满意地点点头，"点击发布。"

系统突然弹窗：

『检测到招聘信息初稿，系统评价：★☆☆☆☆』

方远一愣："才一星？"

系统吐槽模式开启：

"① '吃苦耐劳'这种词，谁看谁跑。你要传递的是'有价值的工作'，不是'苦力活'。"

"② '有养殖经验'？你这就是把90%的人挡在外面。养过鸡的人多了，但有责任心的人不多。"

"③ '面议'？连工资都不敢写，谁敢来？你知道当地劳动力市场的薪资范围吗？"

方远脸一红："那我该怎么改？"

林小雅凑过来看了一眼，笑道："我来教你。"

她拿过方远的手机，开始修改：

**标题：城市农业项目招募农场助手（学习现代农业技术）**

**岗位亮点：**

- 参与灵植培育，学习现代农业管理
- 体验城市农场，朝阳行业
- 工作环境：市中心楼顶农场

**任职要求：**

- 责任心强（第一优先级）
- 愿意学习（有无养殖经验均可）
- 热爱农业，对现代农业感兴趣

**薪资待遇：**

- 底薪3000-4000元 + 绩效奖金
- 提供培训，学习现代农业技术
- 试用期2周，双向选择

**工作内容：**

- 协助农场日常管理（喂鸡、收鸡蛋）
- 参与灵植培育（学习新技术）
- 农场数据记录与分析

方远看着修改后的版本，眼睛越睁越大："这...这完全不一样了。"

"哪里不一样？"林小雅问。

"感觉...更有吸引力了。"方远说，"原来的像招苦力，现在的像招合作伙伴。"

"对，就是这个感觉。"林小雅笑道，"你要让应聘者看到，这不是一份简单的工作，而是一个学习成长的机会。"

方远若有所思："原来招聘不是招'能做事的人'，是招'能一起成长的人'。"

【系统：招聘信息评价更新 ★☆☆☆☆ → ★★★★★】
『标题吸引力提升300%
薪资透明化降低应聘者疑虑
学习成长定位精准
从"招苦力"到"招伙伴"，认知已升级』

【系统：团队组建学习进度 5% → 10%】
【解锁里程碑：首次招聘尝试】

系统界面弹出：

『评价：你的认知已升级，从"找工人"转变为"找伙伴"』

方远深吸一口气，点击"发布"按钮。

屏幕上显示"发布成功"。

"完成了！"他长舒一口气。

林小雅拍拍他的肩膀："恭喜你，迈出了第一步。"

方远看着屏幕，心里既有期待，又有一丝紧张。不知道会收到什么样的简历？第一个应聘者会是谁？

就在这时，手机提示"您有一条新消息"。

方远一愣："这么快？"

林小雅凑过来："我看看是谁。"

方远点开消息，屏幕上显示出第一条应聘信息...
