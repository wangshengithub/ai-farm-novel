# 第238章 她是林小雅

八月三日下午两点，方远如约来到林小雅的工作室。

这是她半年前成立的地方——一个不算大但布置用心的办公空间。墙上贴满了农业科普的剪报，还有客户反馈的截图。最显眼的是一张照片：林小雅在楼顶农场，手里拿着一颗刚摘的生菜，笑得很灿烂。

"设计公司的人三点到。"林小雅一边整理资料一边说，"这次我们得把品牌灵魂和标语都落实进去。"

方远点点头，在沙发坐下。

他看着林小雅忙碌的身影。半年前，她还只是跟着他在楼顶直播的主播。现在呢？她有了自己的工作室，谈合作、做策划、处理客户关系，样样都拿得出手。

"对了，"林小雅突然转头，"今天的设计讨论，你听就好，让我来主导。"

方远愣了一下，然后笑了。

"好，你主导。"

三点的钟声刚敲响，设计公司的团队就到了。一共三个人——设计师、项目经理，还有一个是他们的创意总监。

"林小姐，方先生，久仰。"创意总监是个三十多岁的女性，握手时很专业，"我们看过你们的直播，品牌灵魂找得真好。"

林小雅笑了笑，"谢谢。那我们直接进入正题？"

"当然。"创意总监点头示意，设计师打开投影仪。

屏幕上出现了三组不同的设计方案。

第一组是简约风格——大面积的留白，配上干净的蔬菜图案，"放心菜，方远种"的标语放在正中央。

第二组是手绘风格——每一款产品都有手绘的蔬菜图案，旁边标注着"从种子到餐桌，全程可见"的说明文字。

第三组是农场风格——直接用楼顶农场的实景照片作为包装背景，强调"透明种植"的概念。

林小雅认真地看着每一组方案，时不时在笔记本上记着什么。

几分钟后，她合上笔记本。

"第三组的想法不错，"她开口，"但实景照片会受季节影响，而且每次换产品都要重新拍摄，成本太高。"

设计师点头，"确实，所以我们更推荐第一组或第二组。"

"第一组简约，但缺乏辨识度。"林小雅继续说，"市面上走简约路线的农产品太多了，我们很难脱颖而出。"

"那第二组呢？"项目经理问。

"第二组的手绘风格很好，很亲切，但——"林小雅顿了顿，"它太像'小而美'的手工作坊产品了。我们的定位不是'小而美'，而是'值得信赖的专业品牌'。"

会议室安静了几秒。

方远坐在一旁，看着林小雅。

她没有急着说话，而是在白板上画了几个框框。先排除不符合定位的选项，然后在剩下的可能性中找到最优解。这种思考方式，不是一天两天能练出来的。

"那林小姐觉得应该怎么调整？"创意总监问。

林小雅想了想，"结合第一组和第二组的优点。保留手绘风格，但不是小清新的手绘，而是更专业的插画风格。蔬菜图案要写实，但线条要干净利落。"

她站起来，走到白板前，拿起马克笔画了一个草图。

"这里是品牌标语——'放心菜，方远种'，字体要稳，不能太花哨。下面是产品名称，字体可以活泼一点。最底部放一行小字——'从种子到餐桌，全程可见'，作为信任背书。"

她画完，回头看向设计团队。

"整体色调以绿色为主，但不是那种饱和度很高的绿色，而是更深沉、更稳重的森林绿。这样既符合农业属性，又不会显得太轻浮。"

设计团队的三个人互相看了看。

创意总监的眼睛亮了，"这个方向很好。林小姐，你对品牌定位的理解很到位。"

"因为我理解这个品牌的灵魂是什么。"林小雅笑了，"让每个家庭都放心地吃上健康的蔬菜——这个核心需要在每一个设计细节里体现出来。"

方远坐在沙发上，嘴角不自觉地上扬。

他看着林小雅侃侃而谈，看着她用专业的语言和设计团队沟通，看着她主导整个讨论的走向。

这不是第一次了。她在工作室的工作越来越顺手，谈合作、做策划、处理客户关系，样样都拿得出手。

有时候方远会想，如果没有他，林小雅也能闯出自己的一片天地吧。

"那我们就按照这个方向做深化设计？"创意总监问。

"对，下周三能出初稿吗？"林小雅问。

"没问题。"创意总监点头，"我们会尽快推进。"

送走设计团队后，林小雅回到办公室，长舒了一口气。

"累吗？"方远问。

"还行。"林小雅笑了笑，"就是说话说得有点多。"

她坐下来，拿起桌上的水杯喝了一口。

"对了，今天下午还有一个事。"她说，"有个自媒体的记者想采访我，关于农业科普直播的。"

方远愣了一下，"采访你？"

"对，不是采访我们，是采访我。"林小雅说，"他们最近在做'新农人'系列的报道，觉得我的直播内容很有价值。"

"那你答应了？"

"答应了，四点在他们工作室。"林小雅看了看手机，"还有二十分钟，我得准备一下。"

方远看着她，"需要我陪你去吗？"

"不用。"林小雅摇头，"这是我的采访，你去了反而会影响我的发挥。"

方远笑了，"行，那我等你回来。"

林小雅工作室离这里不远，打车十分钟就到了。采访在他们的会议室进行，记者是个二十多岁的年轻人，看起来很干练。

"林小姐，感谢你接受我们的采访。"记者握了握手，"我们关注你的直播很久了。"

"客气了。"林小雅坐下，"请问吧。"

"第一个问题——你是什么时候开始做农业科普直播的？"

"大概是半年前。"林小雅想了想，"当时我刚开始帮方远直播卖菜，后来发现很多人对现代农业不了解，有很多误解。我就想着，与其一个个解释，不如系统性地做科普。"

"那你觉得，农业科普最大的价值是什么？"

"是打破信息不对称。"林小雅认真地说，"现在很多人对农业的认知还停留在'面朝黄土背朝天'的传统印象里。但实际上，现代都市农业已经有了很大的发展。楼顶种植、无土栽培、智能温室——这些技术让农业生产变得更高效、更可控、更透明。"

记者点头记录。

"那你的直播内容主要是什么？"

"分几类吧。"林小雅说，"一类是种植技术科普，比如怎么选种、怎么施肥、怎么防治病虫害。一类是农产品知识科普，比如不同季节有什么时令蔬菜，怎么挑选新鲜的食材。还有一类是行业洞察，比如农业技术的发展趋势，都市农业的未来可能性。"

"你觉得你的直播和普通的农业科普有什么不同？"

"我有真实的实践。"林小雅笑了，"我不是坐在办公室里查资料然后讲给大家听，而是每天都在楼顶农场里实践。我讲的东西，都是我自己验证过的。这种'第一手经验'，是纯理论科普无法替代的。"

记者眼睛一亮，"这个角度很好。那最后一个问题——你觉得农业科普直播的未来是什么？"

林小雅沉默了几秒。

"我觉得是成为连接生产者和消费者的桥梁。"她说，"现在很多农产品卖不出去，不是因为品质不好，而是因为信息不通畅。消费者不知道怎么找到好的农产品，生产者不知道怎么触达消费者。而农业科普直播，可以同时解决这两个问题——既传递知识，又建立信任。"

记者收起笔记本，"林小姐，今天的采访让我受益匪浅。你的专业性和深度，远超我的预期。"

"谢谢。"林小雅笑了。

"对了，"记者说，"我们这篇报道的标题，我初步想的是《她让农业科普变得有趣又专业》。你觉得怎么样？"

林小雅愣了一下，然后笑了。

"我觉得可以。但还有一个建议——加上'先锋'两个字。"

"先锋？"

"对。"林小雅点头，"因为我做的不只是科普，还是在探索一种新的可能性——农业如何和新媒体结合，如何和都市生活结合。这是一种前沿的尝试。"

记者的眼睛更亮了，"《农业科普先锋：她让农业知识走进都市生活》——这个标题更好。"

采访结束后，记者送林小雅到电梯口。

"林小姐，你的格局让我佩服。"记者说，"期待你的直播越做越好。"

"谢谢。"林小雅笑了。

回到工作室，已经是下午五点了。方远还在沙发上等着，手里拿着一本书。

"怎么样？"方远问。

"还不错。"林小雅坐下来，"记者很专业，问题也问到了点子上。"

"那他们什么时候发报道？"

"下周吧，说是还要整理录音和照片。"

林小雅顿了顿，"对了，他们说标题可能会用'农业科普先锋'这个词。"

方远愣了一下，然后笑了。

"挺好，你配得上这个称号。"

林小雅看着方远，"你吃醋了？"

"没有。"方远摇头，"我是真的觉得你配得上。"

他站起来，走到林小雅面前，蹲下来，握住她的手。

"林小雅，你是独立的。"他说，"不是因为你是方远的女朋友才被人认可，而是因为你本身就很优秀。今天的采访，设计公司的讨论，都证明了这一点。"

林小雅的心里一暖。

"我知道。"她轻声说，"但我还是很高兴听到你这么说。"

"为什么？"

"因为这说明你真的在支持我，而不是在心里觉得'我是方远的女朋友，所以必须支持她'。"

方远笑了，"我是发自内心地为你骄傲。"

两人相视一笑。

这时，林小雅的手机响了。是设计公司发来的消息——初稿会比预期更快，下周一就能出。

"看来设计团队被你打动了。"方远说。

"也许吧。"林小雅收起手机，"那下周一我们再过去看方案。"

"好。"

林小雅站起来，走到窗前。窗外的城市正被夕阳染成金色。

她想起记者最后说的那句话——"你的格局让我佩服"。

格局是什么？

大概就是能看到更大的图景，能想到更远的未来。

半年前，她只是一个跟着方远直播的主播。

半年后，她有了自己的工作室，有了独立的媒体认可，有了"农业科普先锋"的称号。

"方远，"她突然说，"我想做更多。"

"做什么？"

"不只是给我们的品牌做科普，而是给整个行业做科普。"林小雅转过身，"我想让更多人了解都市农业，了解现代农业技术。"

方远看着她，"那你打算怎么做？"

"还没想好。"林小雅笑了，"但我会想出来的。"

她顿了顿，"也许可以和其他农友合作，做一系列的探访视频。也许可以开线下的科普讲座，让城市里的孩子体验种植。也许可以和学校合作，把农业科普带进课堂。"

"这些都是很好的想法。"方远说，"慢慢来，不着急。"

"不着急。"林小雅点头，"但我知道方向是对的。"

她看着方远，"谢谢你一直支持我。"

"应该的。"方远笑了，"我们是伙伴嘛。"

"对，伙伴。"林小雅笑了。

这时，她的手机又响了。

是那个记者发来的消息："林小姐，刚刚编辑部说，如果你有兴趣，我们想邀请你做一个专栏——专门讲都市农业和新农人故事。你考虑一下？"

林小雅看着消息，眼睛亮了。

"怎么了？"方远问。

"他们说想邀请我做一个专栏。"林小雅笑了，"专门讲都市农业和新农人故事。"

"那你打算接吗？"

"当然接。"林小雅收起手机，"这是第一步。"

方远笑了，"那恭喜你，林专栏作家。"

"还没呢，得先写出来才行。"林小雅说，"不过——我会写好的。"

夕阳的余晖洒进办公室，两人的影子在墙上拉得很长。

从今天开始，她不只是"方远的女朋友"。

她是林小雅，一个有独立价值的农业科普先锋。

而这个专栏，会是她独立事业的第一块基石。
