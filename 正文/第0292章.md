# 第292章 团队重建

二月二十五日，下午两点。

楼顶农场办公室，阳光斜照，桌面上摆着几份简历和一个"面试评估表"文件夹。

方远看了看时间。

门外传来敲门声，王磊推门进来。

"方总。"

"下午了。"方远笑，"坐。"

王磊在对面坐下，目光落在桌上的简历上。

"今天的面试……"他顿了顿，"我来主持？"

"对。"方远把简历推过去，"你是温室的负责人，以后招人也是你带。这次面试你来主导，我观察。"

王磊愣了一下。昨天方远说放权，他以为是日常工作的授权，没想到这么快。

"方总，我……"

"有压力？"

"不是压力。"王磊摇头，"就是……招人这么重要的事情，我万一选错人怎么办？"

方远看着他，认真地说："王磊，你跟了我两年多。你对温室的了解，除了我没人比你更深。至于选错人……"

他笑了笑："谁没选错过人？我当初招的第一个销售，试用期就被我辞了。错了就错了，从头再来就是。"

王磊沉默了几秒，然后点头："我明白了，方总。"

"好。"方远把简历翻开，"今天下午两个候选人。第一个是李明，农业专业毕业，在有机农场工作过两年。第二个是陈佳，转行的，之前做IT，对农业很有热情。"

王磊翻看着简历，眉头微皱："方总，这两个人的背景差别挺大的。"

"对。"方远说，"所以我想听听你的判断。"

"我明白了。"王磊又看了一遍简历，在笔记本上写了几个问题。

这几天招聘信息发出去后，收到十几份简历，筛选后只剩下这两个人。

两点二十分，门外传来敲门声。

"请进。"

第一个候选人走了进来。李明，二十七八岁，穿着整洁的衬衫，给人的第一印象是踏实、稳重。

"您好，我是李明。"他微微鞠躬。

"请坐。"王磊开口，语气比平时多了一份沉稳，"我看过你的简历，你在XX有机农场工作过两年？"

"是的。"李明坐下，"我在那边负责温室管理，主要做番茄和黄瓜的无土栽培。"

"那你对水培和雾培有了解吗？"王磊问。

"水培比较熟悉，雾培只在书上见过。"李明实话实说，"不过我愿意学。"

方远坐在一旁，静静地观察。他差点开口问雾培，但忍住了。

王磊继续问："你之前工作的地方，温室面积多大？团队几个人？"

"三千平，一个主管带四个人。"

"那你日常主要负责什么？"

"日常巡查、设备维护、病虫害防治、还有员工培训。"李明回答得很流利，"我们主管有时候不在，我会临时负责一下。"

方远微微点头。这个李明确实有经验，说话也不夸张，是个踏实的类型。

王磊又问了几个问题：为什么离职？对新工作有什么期待？能接受加班吗？李明的回答都很中肯——想要更大的发展空间，能接受旺季加班。

最后一个问题是王磊临时加的。

"如果让你负责一个一千平的温室，你会怎么管理？"

李明想了想，说："我会先熟悉设备和作物，建立日常巡查制度，每天早晚各一次。然后跟员工保持沟通，了解他们遇到的问题。还有……"他顿了顿，"我会做记录，每天的工作和发现都记下来，这样有问题能追溯，有经验能积累。"

方远眼睛一亮。

王磊也点了点头："好，今天的面试就到这里。我们会尽快给你答复。"

李明起身离开后，王磊在评估表上打了个勾，写下几个字：有经验，踏实，有记录习惯。

"你觉得怎么样？"方远问。

"不错。"王磊说，"他有经验，上手快。而且他提到做记录，这个习惯很好。"

"嗯。"方远点头，"不过第二个也要见见，对比一下才知道。"

三点四十分，第二个候选人陈佳进门。

和第一个的踏实不同，陈佳给人的感觉是热情、充满活力。二十六七岁，眼神里带着一种跃跃欲试的光芒。

"您好，我是陈佳。"她笑容灿烂。

"请坐。"王磊依旧是开场白，"我看过你的简历，你之前是做IT的？"

"对，我在互联网公司做了四年程序员。"陈佳说，"但一直对农业很感兴趣，去年开始在自家阳台搞无土栽培，越玩越上瘾，就决定转行了。"

方远微微点头。转行的人他见过不少，有的只是一时兴起，有的却是真的有热情。关键是要看后者。

王磊问："你在家种的是什么？"

"番茄、生菜、还有小黄瓜。"陈佳眼睛亮起来，"我买了套小型水培设备，从配营养液开始学的。第一次种失败了，营养液浓度太高，全烧死了。后来慢慢摸索，现在已经能种出不错的番茄了。"

"那你知道为什么营养液浓度太高会烧苗吗？"王磊追问。

陈佳想了想："因为渗透压？如果营养液浓度太高，根系吸不上水，反而会失水。"

"对。"王磊点头，"那你了解EC值和pH值吗？"

"EC值是电导率，反映营养液浓度；pH值是酸碱度。"陈佳回答，"我家那套设备有检测器，我每两天测一次。"

王磊又问："如果在温室工作，你能接受早上六点起来巡查吗？IT行业通常时间比较自由。"

"能。"陈佳毫不犹豫，"我之前上班也是早九晚九，农业虽然辛苦，但至少有意义。"

"最后一个问题。"王磊说，"如果让你从零开始管理一个温室，你会怎么做？"

陈佳想了想："我会先学习，之前在阳台种是小打小闹，真正的大规模种植肯定不一样。然后请教有经验的人，比如您。"她笑了笑，"还有记录和总结，每次遇到问题都写下来，慢慢积累经验。"

方远和王磊对视了一眼。

记录。两个人都提到了这个习惯。

陈佳离开后，王磊在评估表上也写了几行字：热情、有学习意愿、也有记录习惯。

"怎么样？"方远问。

"两个都不错。"王磊说，"李明有经验，上手快。陈佳虽然没经验，但学习意愿很强，而且也提到做记录。"

"你的判断呢？"

王磊沉默了一会儿，说："如果只能选一个，我倾向李明。因为现在团队缺人，需要能快速上手的。陈佳的热情很可贵，但培养一个新人需要时间。"

方远点了点头："理由呢？"

"李明有经验，培训成本低。"王磊分析，"他性格比较稳重，跟其他员工配合应该没问题。而且他提到做记录，说明他有管理的潜质。陈佳虽然热情，但没有任何农业工作的经验，适应期会比较长。"

方远听完，笑了。

"你的分析很到位。"他说，"那我宣布一个决定——"

王磊坐直了身体。

"从今天开始，温室的人事由你全权负责。"方远说，"招聘、培训、绩效考核，都你说了算。遇到拿不准的事情可以跟我商量，但最终决定权在你。"

王磊愣住了。

"方总，这……"

"你昨天不是问我，怎么才算一个合格的管理者吗？"方远说，"今天就是第一个考验——你做出了判断，而且判断得很合理。接下来就是执行你的判断。"

王磊沉默了几秒，郑重地点头："我明白了，方总。我不会让您失望的。"

"我相信你。"方远站起身，"对了，李明那边你尽快联系，如果他能接受，下周就能来上班。至于陈佳……"

他顿了顿："虽然这次不录用，但她的热情很难得。你可以把她留在人才库，以后有合适的岗位再联系。"

"好，我记下了。"王磊说。

方远走到窗边，看着楼顶的温室。玻璃反射着午后的阳光，里面的作物正在茁壮成长。

"王磊。"他忽然开口。

"在，方总。"

"你刚才面试的时候，有没有注意到一件事？"

"什么？"

"你在问问题的时候，不是照着简历念，而是根据对方的回答追问。"方远说，"这说明你真正在听，在思考。这是一个很好的管理者素质。"

王磊愣了一下，随即笑了："谢谢方总夸奖。"

"不是夸奖，是事实。"方远转过身，"我观察你两个小时了。你的提问很有逻辑，你关注的问题都是关键点——经验、习惯、学习能力。最重要的是，你有自己的判断，而且敢于坚持。"

他停顿了一下："这就是管理者的样子。"

王磊握紧了拳头，眼里闪过一丝激动。

就在这时，系统弹出了提示。

【团队重建进度评估】

【当前时间：2026年2月25日 17:00】

【团队状态：从危机后的不稳定转向重建中】

【稳定性：78% → 85%】

【管理模式转型：30% → 35%】

【评估：本次招聘决策合理，新员工预计一周内入职。团队结构正在优化，管理授权有效推进。】

【建议：继续完善制度框架，为新员工入职做好准备。】

方远看着系统提示，心里有种释然的感觉。

团队在重建，管理制度在落地，王磊在成长。

"对了，你今天的表现，我会记录在你的绩效考核里。"方远说。

王磊脸微微一红："谢谢方总。"

"不用谢。"方远笑了笑，"是你自己做得好。今天辛苦了，早点回去休息吧。"

"好的方总。"王磊收拾好桌上的简历，"那我也先回去准备一下，明天给您一个详细的入职计划。"

王磊离开后，办公室只剩下方远一个人。

他走到窗边，看着楼下的车水马龙。

二月二十五日，下午五点。

距离二月二十八日，还有三天。

方远拿出手机，点开日历。

二月二十八日。

他需要准备的东西还有很多：戒指、场地、台词、还有……

"还有最重要的——"他自言自语，"一颗让她感动的心。"

【系统提醒】

【从创业者到管理者的蜕变，进度：35% → 40%】

方远笑了。

"会的。"他轻声说。

他关掉电脑，转身走出办公室。

阳光正好，一切都充满希望。
